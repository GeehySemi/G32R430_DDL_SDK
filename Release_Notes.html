Release Notes for  G32R430 DDL SDK 

Update History

  • Update device headers, SVD, and DDL drivers to align with the user manual (register naming, bit widths; remove obsolete blocks).
  • Update IAR/GCC/MDK linker scripts and default ITCM load strategy.
  • Upgrade Keil DFP pack to 1.0.4; refresh Flash algorithm and pyOCD target script.
  • Added DDL Driver API documentation (HTML/CHM).
  • Update Tiny example notes (J10 jumpers, clock lock) and header layout consistency.
  • Update GPIO device drivers.
  • Added Eclipse (Clang) project configuration support.
  • Update Flash and RCM device drivers.
  • Added ADC16 reference source configuration functions: DDL_ADC16_SetVerfInternal, DDL_ADC16_SetVerfExternal, DDL_ADC16_GetVerfStatus.
  • Rename COMP register VP_EN/VN_EN to VP_SEL/VN_SEL, and fix input source macro definitions.
  • First Release version of G32R430 DDL SDK.
