G32R430 DDL Driver Documentation

The G32R430 DDL Driver is the peripheral driver layer of the G32R430 DDL SDK. It exposes hardware-oriented C functions and data types for G32R4xx on-chip blocks.

Each driver module consists of a public header in Include/ and, where applicable, an implementation file in Source/. Within a module, symbols are grouped into initialization helpers, configuration functions, and flag/interrupt management routines.

Document organization

  • Peripheral modules are listed under Topics (G32R4xx_DDL_Driver and sub-groups).
  • Files provides a directory view of all driver headers and sources.
  • Data Structures lists DDL_*_InitTypeDef and related types used by the APIs.

For product information and additional documentation, visit Geehy Semiconductor.
