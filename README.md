# G32R430_DDL_SDK
Official software development kit for Geehy G32R430 microcontrollers.

## Current version

- SDK version: V1.0.4
- Supported device: G32R430
- Official package date: 03-August-2026
- Release notes date: October 27th, 2026
- Official download: [G32R430_DDL_SDK_V1.0.4.zip](https://www.geehy.com/uploads/tool/G32R430_DDL_SDK_V1.0.4.zip)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
