&par Example Description

This example demonstrates a simple embedded system initialization sequence for GPIO, DAC,
and comparator peripherals.

- The program initializes an analog input pin for the comparator (PD12) and configures the DAC
to output a fixed voltage (1.65V).
- After initialization, the program enters an infinite loop, where it continuously reads the
comparator output to determine whether the analog input voltage is higher or lower than the DAC
output voltage, and toggles LEDs accordingly.

&par Hardware Description

using COMP1+(PD12)

USART2_TX(PD0)
USART2_RX(PC12)

  - USART2 configured as follow:
  - BaudRate = 115200
  - Word Length = USART_WordLength_8b
  - Stop Bit = USART_StopBits_1
  - Parity = USART_Parity_No
  - Hardware flow control disabled (RTS and CTS signals)
  - Receive and transmit enabled

&par Directory contents

  - COMP/COMP_CompareGpioVsDacInt_OutputGpio/Source/g32r4xx_int.c  Interrupt handlers

&par Hardware and Software environment

  - This example runs on G32R430 TINY Devices.
  - Note: On G32R430 TINY Board, J10 selects whether PA1/PA2 connect to
    LED1/LED2 or the external header. Check the J10 jumper before use.
