&par Example Description

This example demonstrates how to use the ADC16 Analog Window Watchdog (AWD)
feature to continuously monitor input voltage. When the voltage goes beyond
the configured thresholds, an interrupt is triggered, LED2 is turned on, and
relevant information is printed via the serial port.

&par Hardware Description

using ADC1_Channel1(PA1)

USART2_TX(PD0)
USART2_RX(PC12)

  - USART2 configured as follow:
  - BaudRate = 115200
  - Word Length = USART_WordLength_8b
  - Stop Bit = USART_StopBits_1
  - Parity = USART_Parity_No
  - Hardware flow control disabled (RTS and CTS signals)
  - Receive and transmit enabled

&par Directory contents

  - ADC16/ADC16_AnalogWindowWatchdog/Source/main.c                 Main program implementing the test
  - ADC16/ADC16_AnalogWindowWatchdog/Source/g32r4xx_int.c          Interrupt handlers

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V9.60.2.5599
  - Eclipse V4.35.0 RC1 & clang V19.1.1

&par Hardware and Software environment

  - This example runs on G32R430 TINY Devices.
  - Note: On G32R430 TINY Board, J10 selects whether PA1/PA2 connect to
    LED1/LED2 or the external header. Check the J10 jumper before use.
